## 1. Python Fundamentals

* **Variable:** Stores a value that can change.
* **Constant:** Stores a value intended to remain unchanged.
* **Function:** A reusable block of code that performs a task.
* **Module:** A Python file containing reusable code.
* **Package:** A collection of related Python modules.
* **Class:** A blueprint for creating objects.
* **Method:** A function defined inside a class.

## 2. Clean Code, PEP 8, and Debugging

* **Clean Code:** Code that is easy to read, understand, and maintain.
* **PEP 8:** Python's coding style guidelines for writing consistent and readable code.
* **Debugging:** Finding and fixing errors in a program.
